![Ripple 模式选择](assets/mode-switch.png)

轻点是一款轻量的 Mac 视频编辑器，支持呼吸点击圆环和玻璃放大两种模式。点击放置圆环，或框选区域添加定格放大。支持按原分辨率导出，预览与成片效果一致，并提供简体中文和英文界面。
