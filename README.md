# Ripple

语言切换 ➡️ [简体中文](README.zh-Hans.md)

![Ripple demo](assets/demo.gif)

Ripple is a lightweight macOS app that adds translucent, breathing click rings to your videos. Place rings directly on the preview and adjust their timing, duration, size and color with simple controls. Export at the original resolution with matching preview effects, with support for English and Simplified Chinese.
